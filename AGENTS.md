# Development Guidelines

## Approved Technology Stack
- **Framework**: Next.js 15 (App Router)
- **UI & Language**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion, GSAP
- **Icons**: Lucide React
- **Forms & Validation**: React Hook Form, Zod

## Core Rules
- Preserve the approved website visual design and responsive layouts.
- Keep dependencies strictly limited to the approved stack.
- Ensure production builds compile with zero errors.
